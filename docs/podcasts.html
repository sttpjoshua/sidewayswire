GITHUB-SLEUTEL

Nodig om wijzigingen op te slaan. Hij blijft alleen in deze browser.

  1. Open github.com/settings/personal-access-tokens/new
  2. Naam: sidewayswire dashboard, vervaldatum naar keuze
  3. Repository access: Only select repositories → sidewayswire
  4. Permissions → Repository: Contents: Read and write en Actions: Read and write
  5. Generate token, kopieer hem en plak hem hieronder
