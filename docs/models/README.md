# 3D-modellen in het kantoor

Deze modellen komen van Kenney (kenney.nl), uit de Starter Kits op GitHub:

- `racing/`: KenneyNL/Starter-Kit-Racing (pickups, start/finish-boog, tenten, bos)
- `city/`: KenneyNL/Starter-Kit-City-Builder (gebouwen op de achtergrond, bomen)

Beide onder de MIT-licentie, copyright Kenney; de licentietekst staat in elke map (LICENSE.txt).
De rest van het terrein (garages, auto's, poppetjes) is zelf gemaakt in `docs/office3d.js`.
